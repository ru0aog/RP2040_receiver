# 📻 Pico-SDR Digimode Receiver

[![Platform: RP2040](https://shields.io)](https://raspberrypi.com)
[![Framework: Arduino-Pico](https://shields.io)](https://github.com)
[![License: MIT](https://shields.io)](LICENSE)

Высокоэффективный программно-определяемый радиоприемник (**SDR**) на базе микроконтроллера **Raspberry Pi Pico (RP2040)**. Проект реализует полный тракт цифровой обработки сигналов (DSP), банк фильтров Гёрцеля для декодирования любительских цифровых мод (**CW, RTTY, Olivia, MFSK**), потоковое вещание **USB Audio** и передачу данных FFT-спектра в реальном времени.

По умолчанию приемник настроен на частоту **3.6 МГц** (меняется константой `RX_FREQ_HZ`).

---

## 🔥 Возможности

* **Прямая оцифровка:** Захват радиосигнала встроенным быстрым ADC RP2040 на частоте детонации `~250 ksps`.
* **Квадратурный LO без джиттера:** Аппаратный делитель системных тактов формирует идеальные сдвинутые по фазе сигналы гетеродина.
* **Цифровой DDC:** Комплексный NCO-сдвиг промежуточной частоты (ПЧ), децимация CIC-фильтром и каскад фильтров Half-band FIR снижают частоту до базовой полосы `~15.6 ksps`.
* **Многоканальный банк Гёрцеля:** Вычисление спектра по ~500 узким каналам (шаг `~3.9 Гц`) для прецизионной работы тональных декодеров цифровых мод.
* **FFT Анализатор:** 1024-точечное быстрое преобразование Фурье с автоматической выгрузкой кадров `#BEGIN` / `#END` в Serial-порт.
* **USB Audio Гаджет:** NBFM-демодуляция, автоматическая регулировка усиления (AGC) и ресемплинг (SRC) в поток `44.1 кГц` через стек TinyUSB.
* **PC Телеметрия:** Готовый Python-скрипт в `tools/rp2040_spectrum.py` для визуализации водопада и спектра на компьютере.

## 🏗 Архитектура системы

Проект задействует **оба ядра RP2040**. Взаимодействие между ядрами реализовано через асинхронные lock-free SPSC-очереди (Single Producer Single Consumer) с аппаратными барьерами памяти `__dmb()`.

```mermaid  
flowchart TD  
    subgraph Core1["Core 1 — Реал-тайм DSP тракт"]  
        ADC["ADC + DMA<br/>(ping-pong ~250 ksps)"] --> DC["DC-remove фильтр<br/>(EMA)"]  
        DC --> NCO["NCO комплексный сдвиг<br/>ПЧ ~+7.4 кГц"]  
        NCO --> CIC["CIC Фильтр<br/>(Децимация /2)"]  
        CIC --> HB["2 × Half-band FIR<br/>фильтра"]  
        HB --> Q["SPSC-очередь<br/>(Поток 15.625 ksps)"]  
    end  

    subgraph Core0["Core 0 — Arduino & Вывод данных"]  
        Q --> DEC["Декодеры мод<br/>(CW / RTTY / Olivia / MFSK)"]  
        Q --> FFT["1024-FFT спектр<br/>→ Вывод в Serial"]  
        Q --> AF["NBFM + AGC + SRC<br/>→ USB Audio (TinyUSB)"]  
    end  

    LO["Квадратурный LO<br/>(clk_sys делитель D=9)"] --> ADC
```

## ⚙️ Тактирование и PLL

Для достижения максимального качества приема и отсутствия фазовых шумов применена кастомная карта частот:
1. Системная шина `clk_sys` разогнана до **129.333 МГц** (VCO настроен на `1164 МГц` с делителем `9`). При такой конфигурации шаг аппаратного деления для частоты приема **3.6 МГц** является строго целым числом (`D = 9`), что **полностью устраняет джиттер**.
2. Периферийная шина `clk_peri` принудительно зафиксирована на источнике `pll_usb` (**48 МГц**). Благодаря этому контроллер USB (TinyUSB) и модуль ADC работают строго в паспортных режимах и не сбоят при разгоне вычислительных ядер.

## 🛠 Сборка и прошивка

### 1. Подготовка окружения
1. Установите **Arduino IDE** (версии 2.x или новее).
2. Добавьте сторонний индекс плат в *Настройки -> Дополнительные ссылки для Менеджера плат*:
   ```text
   https://github.com/releases/download/global/package_rp2040_index.json
   ```
3. Через *Менеджер плат* найдите и установите платформу **Raspberry Pi Pico/RP2040 by Earle Philhower**.

### 2. Конфигурация компиляции
В меню **Инструменты (Tools)** выберите следующие параметры:
* **Плата (Board):** `Raspberry Pi Pico`
* **USB Stack:** `Adafruit TinyUSB` *(Обязательно для работы USB Audio)*
* **Частота процессора:** Отставьте значение по умолчанию (карта тактов переназначится программно внутри `vfo_hardware.cpp`).

### 3. Загрузка
1. Откройте файл `RP2040_receiver.ino`.
2. Переведите Pico в режим загрузчика (удерживая кнопку `BOOTSEL` при подключении USB).
3. Нажмите кнопку **Загрузка (Upload)**.
4. После прошивки откройте *Плоттер потерей* или *Монитор порта* на скорости `115200`. В лог пойдут маркеры запуска `# RX_STARTED`, статистика очередей и сырые кадры FFT.

## 💻 Использование Python-вьюера

Для мониторинга эфира и настройки на станции используйте скрипт визуализации. Он считывает текстовые кадры FFT из виртуального COM-порта и строит интерактивный водопад.

```bash
# Установите зависимости (требуется python 3.x)
pip install pyserial numpy matplotlib

# Запуск (замените порт на ваш актуальный, например COM3 в Windows)
python3 tools/rp2040_spectrum.py /dev/ttyACM0
```

## 🎯 Настройка частоты приема

Рабочая частота жестко зашита в начале файла `RP2040_receiver.ino`:

```cpp
static constexpr uint32_t RX_FREQ_HZ = 3600000UL; // 3.6 MHz (80m band)
```

> [!WARNING]
> **Важное замечание по смене частоты:**  
> При значительном изменении константы `RX_FREQ_HZ` убедитесь, что коэффициент деления в `vfo_quadrature_start()` остается целым числом по отношению к `clk_sys`. Если деление станет дробным, фазовый джиттер встроенного ШИМ/делителя резко снизит динамический диапазон приемника по забитию. При необходимости скорректируйте инициализацию `VCO` в коде инициализации частоты.
